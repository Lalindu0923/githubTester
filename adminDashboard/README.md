# Admin Dashboard

A React-based admin dashboard for managing the system, users, and administrative tasks.

## Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Lint

```bash
npm run lint
```

### Preview

```bash
npm run preview
```

## Features

- Manage users (students, teachers, parents)
- System settings and configuration
- View analytics and reports
- Monitor system health
- Manage permissions and access control

## Project Structure

```
src/
  ├── components/       # React components
  ├── routes/          # Router configuration
  ├── styles/          # CSS files
  ├── data/            # Data files
  ├── App.jsx          # Main app component
  ├── main.jsx         # Entry point
  └── index.css        # Global styles
```
