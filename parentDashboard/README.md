# Parent Dashboard (Vite + React)

This project was migrated to a Vite + React app. Key files:

- `index.html` — Vite entry
- `src/main.jsx` — React entry
- `src/App.jsx` — main component
- `src/styles.css` — styles
- `src/data/parents.json` — sample data

Quick start:

```bash
npm install
npm run dev
```

The dev server will open your browser automatically.

Build for production:

```bash
npm run build
npm run preview
```
